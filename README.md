# WordBoom Reader

The original WordBoom reading and vocabulary workspace for Norwegian Bokmål, with offline English help and the familiar learning progress sidebar.

- [Download WordBoom Reader 1.0.2 for Windows x64](https://github.com/kevin-fjord/wordboom-reader-releases/releases/download/v1.0.2/WordBoom-Reader-v1.0.2-Windows-x64.zip)
- [Release notes and checksum](https://github.com/kevin-fjord/wordboom-reader-releases/releases/latest)

Extract the complete ZIP and run WordBoomReader.exe. Requires .NET Framework 4.8 and Microsoft Edge WebView2 Runtime.

Import a text file, paste text or extract Norwegian text from an image. Organize your materials in folders and subfolders. Listen to a Norwegian sentence or word once with the bundled offline voice. The app stores your materials and progress in its own local data folder.
