# WordBoom Reader

An offline Windows reader for Norwegian Bokmål, with English translations and vocabulary meanings.

- [Download WordBoom Reader 1.0.0 for Windows x64](https://github.com/kevin-fjord/wordboom-reader-releases/releases/download/v1.0.0/WordBoom-Reader-v1.0.0-Windows-x64.zip)
- [Release notes and checksum](https://github.com/kevin-fjord/wordboom-reader-releases/releases/latest)

Extract the complete ZIP and run WordBoomReader.exe. Requires .NET Framework 4.8 and Microsoft Edge WebView2 Runtime.

Import a text file, paste text or extract Norwegian text from an image. Organize your materials in folders and subfolders. The app stores your materials and progress in its own local data folder.

[Full WordBoom edition](https://github.com/kevin-fjord/wordboom-releases/releases/latest)
